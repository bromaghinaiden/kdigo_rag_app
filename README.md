# README

This project is a RAG-based web app that allows users to query against the KDIGO guidelines for CKD management. KDIGO guidelines are widely recognized as a valuable source of information, but can be difficult to get targeted meaning from. The goal of this app is to enable users to quickly receive clear, helpful answers based on the guidelines when asking about CKD managment. 

The app is built in Python and uses Langchain to handle RAG. Streamlit is used for deployment and UI.
